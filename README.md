## Features

- **Conversational Interface**: Interactive chat-based IT support assistant
- **File Processing**: Download and process files generated by the agent
- **Image Generation**: Support for generating and saving charts/visualizations
- **Azure Integration**: Built on Microsoft Foundry and Azure AI Projects
- **Function Calling**: Execute tools and functions through the agent

## Prerequisites

- Python 3.13 or higher
- An Azure subscription with Microsoft Foundry access
- Azure CLI configured with appropriate credentials
- Git (for cloning the repository)

## Setup

### 1. Clone the Repository

```bash
git clone <repository-url>
cd it-support-ai-agent
```

### 2. Create Virtual Environment

```bash
python3 -m venv labenv
source labenv/bin/activate  # On macOS/Linux
# or
labenv\Scripts\activate  # On Windows
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure Environment Variables

Create a `.env` file in the project root with the following variables:

```env
PROJECT_ENDPOINT=<your-azure-ai-project-endpoint>
AGENT_NAME=it-support-agent
```

You can obtain the `PROJECT_ENDPOINT` from your Azure AI Foundry project in the Azure Portal.

## Running the Agent

Start the interactive agent with:

```bash
python agent_with_functions.py
```

You'll be presented with an interactive chat interface:

```
============================================================
IT Support Agent Ready!
Ask questions, request data analysis, or get help.
Type 'exit' to quit.
============================================================

You: 
```

### Example Interactions

- Ask questions about IT support topics
- Request data analysis or reports
- Upload and process files
- Generate visualizations and charts

Type `exit` or `quit` to end the conversation.

## Key Components

### `agent_with_functions.py`

The main script that:
- Connects to the Microsoft Foundry project
- Loads the IT support agent
- Manages conversations with the agent
- Handles file downloads and image generation
- Processes agent responses

### Core Functions

- **`get_output_path(filename)`**: Creates unique paths for generated files
- **`save_bytes(file_bytes, filename)`**: Saves binary content to disk
- **`save_image(image_data, filename)`**: Saves base64-encoded images
- **`download_container_file(...)`**: Downloads files from Azure containers
- **`format_output_text(...)`**: Processes and formats agent responses

## Output Files

Generated files are automatically saved to the `agent_outputs/` directory, including:
- Downloaded files
- Generated charts and images
- Analysis results

## Troubleshooting

### "PROJECT_ENDPOINT not set" Error
- Ensure your `.env` file exists and contains `PROJECT_ENDPOINT`
- Verify the value is correct from your Azure AI Foundry project

### Authentication Issues
- Run `az login` to authenticate with Azure
- Ensure your Azure account has access to the Foundry project

### Missing Dependencies
- Run `pip install -r requirements.txt` again
- Ensure your virtual environment is activated
